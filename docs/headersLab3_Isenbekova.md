## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTex в документации проекта

#### Markdown — это облегчённый язык разметки текста. Его главная особенность в том, что он читается как обычный текст даже без обработки, но при этом позволяет легко форматировать документы: делать заголовки, списки, ссылки, выделять текст жирным или курсивом. Файлы Markdown имеют расширение .md.

#### GitHub / GitLab — для оформления файлов README.md, документации к проектам, описаний коммитов и pull request'ов. Документация и блоги — в системах вроде Jekyll, Hugo, Docusaurus; на платформах вроде Reddit, Stack Overflow, Discord, Telegram (в некоторых режимах). Заметки и личные записи — в приложениях Obsidian, Notion, Typora, Joplin. Техническая документация — для инструкций, API-справок и т.д.

#### Простота и скорость. Не нужно запоминать сложные теги (как в HTML) — достаточно нескольких символов (#, *, -), чтобы оформить текст. Пишется быстро, читается легко. Универсальность и поддержка. Markdown понимают почти все платформы для разработки (GitHub, GitLab, VS Code, Jira). Один и тот же файл откроется и в браузере, и в редакторе, и в командной строке. Удобство для документации. С его помощью удобно вести README, описывать проект, писать инструкции и комментарии к коду — всё хранится прямо в репозитории рядом с исходниками, версионируется вместе с ними и легко обновляется.
